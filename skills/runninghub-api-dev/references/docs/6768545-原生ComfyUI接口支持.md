## 🔗 接口调用方式

通过以下地址调用 RunningHub 的 ComfyUI 接口：

```
默认使用24G显存的机器：
https://www.runninghub.cn/proxy/your-api-key
如果想使用48G显存机器：
https://www.runninghub.cn/proxy-plus/your-api-key
```

该地址功能等同于本地部署的 ComfyUI 地址：

```
http://127.0.0.1:8188
```

目前已支持以下平台和插件的接入：

* [EasyAI](https://doc.51easyai.com/use/easyai-workflow/runninghub)
* [酒馆AI（SillyTavern）](https://github.com/SillyTavern/SillyTavern)
* [Krita ComfyUI 插件](https://github.com/Acly/krita-ai-diffusion)

更多插件支持正在持续开发中，如有特定需求，欢迎联系我们。

---

## 🧠 关于模型管理

你可以在 RunningHub 官方页面中访问 **模型库**：

1. 点击收藏你需要的模型；
2. 在第三方平台中即可选择并使用已收藏模型；
3. 如果你想使用私有模型，可上传至 RunningHub 并收藏，即可使用。
