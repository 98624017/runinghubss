# 万相2.6-参考生视频Flash

- [官网明确] 页面类型：API
- [官网明确] 官方地址：`https://www.runninghub.cn/runninghub-api-doc-cn/api-422326015.md`
- [官网明确] 页面编号：`422326015`
- [官网明确] 本地文件：`references/endpoints/422326015-万相2.6-参考生视频Flash.md`
- [官网明确] 索引摘要：万相2.6-参考生视频Flash是阿里通义万相2.6系列的快速参考生视频模型，支持上传最多5张参考图像，基于参考图的角色身份、风格和场景布局生成新视频。该版本生成速度更快，支持720P/1080P两种分辨率，视频时长可选5秒或10秒，可生成带音频或无声视频，支持单镜头和多镜头叙事模式。
- 分类：`标准模型 API > 视频生成 > 万象 2.6`
- Tags：`标准模型 API/视频生成/万象 2.6`
