## 真实验证补充

- [真实验证] 2026-03-08：`taskId=0` 返回 `301 taskId must be positive`。
- [真实验证] 2026-03-08：不存在的正整数 `taskId` 返回 `807 APIKEY_TASK_NOT_FOUND`。
- [真实验证] 2026-03-08：仅传 `Authorization` 与 `taskId`、不传 body 中 `apiKey` 时返回 `301 must not be blank`。
