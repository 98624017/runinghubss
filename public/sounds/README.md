# Sound Assets

This directory contains sound files used for task notifications.

## Required Files

### `task-complete.mp3`

- A short notification chime played when a task completes.
- **Size limit**: less than 50KB.
- **Format**: MP3 (widely supported across browsers).
- **Duration**: recommended 1-3 seconds.

Place a suitable `.mp3` file in this directory and name it `task-complete.mp3`.
